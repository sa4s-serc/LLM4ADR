This directory contains the code and results for the efficiency evaluation of DRAFT with respect to other approaches.
The approaches are numbered as follows:

1. Zero-shot Prompting
2. RAG Few-shot
3. Fine-tuning
4. DRAFT using Flan-T5 model run on a CPU machine <br> 4_gpu. DRAFT using Flan-T5 model run on a GPU machine
5. DRAFT using Llama-3 model

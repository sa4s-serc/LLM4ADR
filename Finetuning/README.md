This directory contains the code, output and metrics for the finetuning approach used in the paper.

1. 'Code' contains the code used for finetuning the models.
2. 'Graphs' contains the training and validation loss data for the finetuned models.
3. 'metrics' contains the metrics for the finetuned models. (blue score, rouge score, etc.)
4. 'results' contains the results of the finetuned models on the test set.

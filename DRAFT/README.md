This directory contains the code, output, metrics, and other details for the DRAFT approach.

1. The code is in the 'code' directory.
2. The 'Graphs' directory contains the training and validation loss graphs for the DRAFT approach.
3. The 'metrics' directory contains the calculated metrics for the DRAFT approach (bleu, rouge, betrscore).
4. The 'results' directory contains the output of the DRAFT approach in jsonl format.

This directory contains the code, output and metrics for the zero-shot prompting approach used in the paper.

1. 'Code' contains the code used for prompting the models.
2. 'metrics' contains the metrics for the models. (blue score, rouge score, etc.)
3. 'results' contains the results of the models on the test set.

All models run on ada - t5 and flan-t5 have been on records with less than 2500 length (4950 frequency)

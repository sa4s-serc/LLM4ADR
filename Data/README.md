This directory contains all the data files used in the paper.

1. 'all_ADRS' contains all the ADRs scraped from the MSR Study
2. 'data-scripts' contains the scripts used to process the ADRs and extract the context and decision from each ADR.
3. 'repositories' contains the details of the repositories from which the ADRs were scraped.
4. 'ADR-data' contains the final data used in the paper. Further details on the data can be found in the README file in this directory.

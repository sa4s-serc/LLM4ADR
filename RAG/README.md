This directory contains the code, output and metrics for the RAG few-shot approach used in the paper.

1. 'Code' contains the code used for retrieval and prompting the models.
2. 'embeds' contains the embeddings of the datasets used for retrieval.
3. 'metrics' contains the metrics for the models. (blue score, rouge score, etc.)
4. 'results' contains the results of the models on the test set.
